# 上线前清单

这份清单从一个挑剔的海外采购（或你的潜在客户）的角度，核对页面上**可以被查证的说法**。这些说法都是你写在页面上的，我没有核实它们的真假，只检查了它们之间是否一致、读者会不会追问。

## 一、需要你处理的内容矛盾

| # | 位置 | 问题 | 建议 |
|---|---|---|---|
| 1 | `/seo/`、`/en/` 成绩区 | "3× 六个月内自然询盘增长"是最初模板里的示例数字。你已经把另外两个数字改成了 100+ 和 1000+，案例页里也没有任何内容支撑 3×。 | 有真实数据就保留并在案例页写明基线和时间；没有就删掉这一条。 |
| 2 | `/about`、`/en/about` "真实作品" | 写的是"杭州XX传动件公司"，"XX"看起来是匿名占位。案例页署名是"TONGLU INC."。读者会问：这是同一个客户吗？ | 说明是同一家还是不同客户；如果是匿名，写成"一家杭州的传动件制造商（应客户要求匿名）"，比"XX"更可信。 |
| 3 | `/case-study`、`/en/case-study` 客户评价 | 引言原文是最初模板里我写的示例句子，现在署了"Bob，TONGLU INC."。如果 Bob 没有说过这句话，这是以真人的名义发表他没说过的话。 | 发给 Bob 确认或让他改成自己的原话。下面有一段可以直接发的话术。 |
| 4 | 案例页标题 | "不买一条广告"是一个可被追问的事实陈述。 | 确认这个客户在这段时间内确实没有为这个站投放广告；不确定就把标题改成"从无人知晓到 Google 首页。"。 |
| 5 | 全站 | 多数页面反复用"我们"，关于页和部分段落用"我"，首页和服务页又写"一个人对结果负责"。 | 不是错误，但读者会注意到。统一成"我"或"我们"其中一种会更干净。 |
| 6 | 联系页 | "每条询盘都由本人亲自回复"、"通常一个工作日内回复"是对访客的承诺。 | 确认你能做到；做不到就改成你能兑现的说法。 |

**给 Bob 的确认话术（可直接发）：**

> Bob 你好，我在更新自己的网站案例页，想引用你们公司的一句评价：「第一次，是买家来找我们，而不是我们花钱被看到。询盘质量更好了，而且是真正属于我们的。」署名写"Bob，TONGLU INC."。这句话是否符合你的真实看法？你可以直接改成你自己的话，也可以告诉我不同意署名。确认后我再上线。

## 二、读者会追问的说法与需要备好的证据

| 页面上的说法 | 一个挑剔的读者会问 | 建议备好 |
|---|---|---|
| 10 年经验（关于页） | 做过哪些站？ | 2 到 3 个可公开的站点或匿名案例 |
| 100+ 商业关键词在 Google/Bing 首页（关于页、案例页、首页） | 哪些词？什么时间？在哪个国家？用什么工具测的？ | Search Console 或排名工具的导出截图，注明日期和国家 |
| 重建 1000+ 页面（案例页、首页） | 是产品页还是分类页？ | 一份页面类型的简单构成 |
| 6 个月内收到首批有效询盘（案例页） | 什么算"有效询盘"？ | 询盘来源的记录（哪怕只是匿名统计） |
| 工业/农业机械配件、传动件方向（关于页） | 有没有这个行业的产品知识？ | 页面上已有 E-E-A-T 内容，可以再补一篇行业文章作为证据 |

## 三、技术上线步骤

- [ ] 填好 `public/contact-form.js` 的 `FORM_ENDPOINT`，并按 README 把域名加进 `_headers` 的 `connect-src`
- [ ] `npm run build && npm run check` 无错误
- [ ] 部署后 `npm run smoke -- https://taovate.com` 全部通过
- [ ] 在 `/contact` 和 `/en/contact` 各提交一条真实询盘，确认收到
- [ ] 确定主域名（`taovate.com` 或 `www`），另一个 301 到主域名
- [ ] Google Search Console 添加站点，提交 `https://taovate.com/sitemap.xml`
- [ ] 在国内多个地区的网络环境下打开一次网站，确认字体和页面能正常加载（我在开发环境里无法测试这一点）
- [ ] 把 `docs/` 之外你不想公开的内容检查一遍：仓库公开后所有文件都能被看到
